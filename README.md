# Easy-AGS

Легкий, удобный и точный автокликер/макрос для игры Squad. 

## Особенности
- **Точность**: Использует высокоточный таймер (`time.perf_counter`) для точного удержания клавиш.
- **Оверлей**: Удобный минималистичный оверлей (темная тема) поверх окон. Окно можно перетаскивать мышкой.
- **Бинд**: Срабатывает на нажатие клавиши `Э` (или английской апостроф `'`).
- **Безопасность**: Автоматически запрашивает права администратора, которые необходимы для работы макросов в большинстве игр.
- **Авто-закрытие**: Скрипт отслеживает процесс игры `squad.exe` (или аналогичный) и автоматически закрывается, когда вы выходите из игры.

## Использование
1. Запустите приложение от имени Администратора (программа сама попросит права при запуске).
2. Введите нужное время удержания в секундах (например, `0.70`).
3. Нажмите кнопку **"НАВОДКА"**. Цвет кнопки изменится на синий, подтверждая запоминание времени.
4. В игре наведитесь и нажмите клавишу **`Э`** (на английской раскладке **`'`**).
5. Программа зажмет клавишу `S` на указанное количество секунд.

## Требования для запуска из исходников
Для запуска скрипта вам понадобится Python 3 и следующие библиотеки:
```bash
pip install keyboard psutil
```
*(Для работы `keyboard` требуются права администратора)*

## Сборка в EXE
Вы можете собрать проект в `.exe` файл с помощью `pyinstaller` и приложенного файла `.spec`:
```bash
pip install pyinstaller
pyinstaller ags_macro.spec
```
Готовый `exe` файл появится в папке `dist`.
