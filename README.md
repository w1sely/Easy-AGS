# Easy-AGS

Легкий, удобный и умный баллистический калькулятор-макрос для наводки АГС в игре Squad. 

## Особенности
- **Встроенная баллистика**: Вам больше не нужно сверяться с таблицами времени! Введите дистанцию до цели в метрах, и скрипт с помощью математической интерполяции автоматически рассчитает идеальное время зажатия с точностью до тысячных долей секунды.
- **Оверлей и Сворачивание**: Минималистичный прозрачный оверлей (темная тема) без рамок поверх окон игры. Включает специальную кнопку `_` для сворачивания в панель задач (защита от пропадания окна при Alt-Tab).
- **Высокая Точность**: Использует кастомный высокоточный таймер (`time.perf_counter`) для абсолютной точности удержания клавиши (в отличие от стандартного `time.sleep()`).
- **Надежный Бинд**: Срабатывает на нажатие клавиши `Э` (или английской апостроф `'`). Используется аппаратный скан-код (Scan code 40), поэтому макрос работает безотказно независимо от выбранной языковой раскладки в Windows.
- **Безопасность**: Автоматически запрашивает права администратора через UAC, которые необходимы для взаимодействия с DirectX играми и обхода античита.
- **Авто-закрытие**: Скрипт сканирует процессы Windows и при закрытии игры `Squad` автоматически завершает свою работу, не оставляя фонового мусора.

## Использование
1. Запустите приложение от имени Администратора (программа сама попросит права при запуске).
2. Запустите Squad в режиме **"Окно без рамок" (Borderless)**, чтобы оверлей отображался поверх игры.
3. Введите точное расстояние до цели в **метрах** (например, `1096`).
4. Нажмите кнопку **"РАСЧЕТ"**. Скрипт мгновенно просчитает баллистику, и на кнопке появится точное время (например, `1.423с`), подтверждая готовность.
5. В игре наведитесь по азимуту и в нужный момент нажмите горячую клавишу **`Э`** (или **`'`**).
6. Программа зажмет клавишу `S` (отпускание ствола АГС) ровно на высчитанное количество времени.

## Требования для запуска из исходников
Для запуска скрипта вам понадобится Python 3 и следующие библиотеки:
```bash
pip install keyboard psutil
```
*(Для работы `keyboard` требуются права администратора)*

## Сборка в EXE
Вы можете собрать проект в один независимый `.exe` файл с вшитым манифестом прав администратора:
```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --uac-admin ags_macro.py
```
Готовый `exe` файл появится в папке `dist`.
